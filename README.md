# Student Resume Website

A simple **Student Resume Web Page** created using HTML. This project demonstrates basic HTML concepts such as headings, paragraphs, tables, lists, forms, and input fields.

## 📌 About the Project

This project is a basic resume webpage for a second-year **B.Tech Computer Engineering student**.

The webpage contains:

* Student introduction
* Education details
* Technical skills
* Contact form

## 🛠️ Technologies Used

* **HTML5**
* Basic HTML Forms
* HTML Tables
* HTML Lists

## 📂 Project Structure

```text
student-resume/
│
├── index.html
└── README.md
```

## ✨ Features

### 👩‍💻 Student Introduction

Displays the student's name and a short introduction.

### 📩 Contact Form

The webpage includes a simple contact form with:

* Name field
* Email field
* Message textarea
* Submit button

## 🚀 How to Run

1. Clone this repository:

```bash
git clone <your-repository-url>
```

2. Open the project folder.

3. Open `index.html` in any web browser.

That's it! The resume webpage will be displayed.
